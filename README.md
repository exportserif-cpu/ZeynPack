## 🏷️ المنتجات / Ürünler / Products

- **Shrink Sleeve** — أكمام الانكماش بطباعة 360°
- **Yapışkanlı Etiket** — ملصقات ذاتية اللصق (Kuşe · PP · PE · Transparent)
- **Barkod ve Termal Etiket** — ملصقات الباركود والحرارية
- **Özel ve Promosyon Etiketleri** — ملصقات خاصة (Hot Foil · Embossing)

## 🛠️ التقنيات / Teknoloji / Tech Stack

- HTML5 + CSS3 + Vanilla JavaScript — بدون بيلد، موقع ثابت بالكامل
- خط Cairo (Google Fonts) — دعم كامل للعربية والتركية واللاتينية
- رسومات SVG يدوية + صور مولّدة بالذكاء الاصطناعي بهوية الشركة (كحلي `#0b2545` + برتقالي `#e8631b`)
- متجاوب مع جميع الشاشات (RTL / LTR)

## 🚀 النشر / Deployment

- **GitHub Pages:** مفعّل من الفرع `main` (المجلد الجذر)
- **Local nginx:** نفس الملفات تُخدم تحت `/zeynpack/` — المسارات نسبية بالكامل فتعمل في أي مسار

## ⚙️ التشغيل محلياً / Local Development

```bash
# أي خادم ملفات ثابتة:
python3 -m http.server 8080
# ثم افتح: http://localhost:8080/
```
